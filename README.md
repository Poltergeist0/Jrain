# Description

This is a collection of data types, utilities and classes with base functionality for some programs that I used in my personal projects. I am releasing it because I haven't used it in the last ten years (as of 2026).
This project was originally written in Java 8 and uses some immutable data types from Guava.


# Dependencies

This project depends on Guava 30.1 (included in the **lib** directory). Guava was developed by Google and was released under Apache License 2.0 . More information about Guava (at the time of writing this) can be found in
https://github.com/google/guava
